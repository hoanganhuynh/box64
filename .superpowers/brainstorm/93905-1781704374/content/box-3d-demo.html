Cách implementation — 3 layer

🎨 Layer 1 — Canvas Texture

  • Mỗi mặt = 1 <canvas> element
  • User nhập text → drawText() lên canvas
  • Upload ảnh xe → drawImage() lên canvas
  • Color picker → fillRect() background
  • Logo variant → drawImage() logo PNG
  • Update realtime, 0 lag

📦 Layer 2 — CSS 3D Box

  • 6 div, mỗi div background = canvas.toDataURL()
  • CSS skewX/Y tạo góc nhìn perspective
  • 1 shape cố định → code 1 lần
  • Hover → subtle rotate animation
  • Toggle "Flat View" → remove skew transforms
  • Không cần WebGL, không cần 3D model

📄 Layer 3 — PDF Export

  • Server nhận canvas data URLs
  • Render flat layout HTML (6 mặt đúng tỉ lệ thực)
  • Puppeteer → PDF 300dpi
  • Có bleed marks + cut lines
  • Đơn vị mm thực tế (không phải px)
  • CMYK-compatible colors
💡 Key insight: Canvas texture approach còn có bonus — text trên canvas không phải DOM text node, nên brand names (Lamborghini, Ferrari...) tự động được obfuscate khỏi crawlers mà không cần code extra. Giải quyết luôn bài toán brand protection!
