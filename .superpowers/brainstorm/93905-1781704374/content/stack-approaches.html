Tech Stack — 3 Approaches

Bạn bán cho SEA market → Singapore region = latency tốt cho VN, TH, MY, ID. Pick 1 hướng.

A

Vercel + Supabase ★ Recommended

Next.js 15 → deploy Vercel (CDN toàn cầu) · Supabase Singapore (PostgreSQL + auth + file storage) · Stripe + PayPal · Resend email

Pros

  • Deploy tự động khi push git
  • Singapore DB = ~20ms latency từ VN
  • Supabase lo backup tự động
  • Claude Code build nhanh nhất với stack này
  • Scale tự động khi có traffic spike

Cons

  • Chi phí tăng theo traffic (nhưng free tier rộng)
  • Phụ thuộc vendor

💰 Est. cost: $0-25/tháng (ban đầu) → $50-100/tháng khi scale

B

VPS Singapore + Docker

Next.js self-hosted · PostgreSQL tự quản lý · MinIO cho file storage · Nginx reverse proxy · Coolify để deploy dễ hơn

Pros

  • Chi phí cố định ~$20-40/tháng
  • Kiểm soát hoàn toàn
  • Dữ liệu không qua bên thứ 3

Cons

  • Phải tự lo backup, SSL, updates
  • DevOps overhead cao
  • Downtime khi maintain
  • Build chậm hơn với Claude Code

💰 Est. cost: $20-40/tháng fixed (DigitalOcean/Vultr Singapore)

C

Vercel + PlanetScale/Neon + Cloudinary

Next.js → Vercel · Neon (serverless PostgreSQL) · Cloudinary (image transform + storage) · Phù hợp nếu ảnh xe là core feature cần optimize

Pros

  • Cloudinary tự resize/optimize ảnh xe upload
  • Neon = serverless, không trả tiền khi idle

Cons

  • Nhiều vendor → phức tạp hơn A
  • Cloudinary có thể đắt khi traffic cao
  • Supabase đã làm được tất cả điều này rồi

💰 Est. cost: $0-50/tháng tùy usage

Tại sao A là tốt nhất cho case của bạn?

Supabase đã bao gồm: PostgreSQL · Auth (phone OTP cho sổ địa chỉ) · File Storage (ảnh xe upload) · Realtime (order tracking) · Backup tự động. Đây là lý do bạn mention "backup mỗi tháng" — Supabase lo hết. Vercel lo CDN + deploy. Bạn chỉ cần code.
