UX Flows — Box64

Chi tiết từng flow quan trọng · UX improvements đã tích hợp

Flow 1 — Box Designer (/design)
Step 1
Chọn template
Size + loại hộp
Step 2
Upload ảnh xe
Crop + position
Step 3
Customize
Text, màu, logo
Step 4
Preview & Order
3D xoay + PDF

Step 1 — Chọn template

  • Grid cards: MiniGT / Poprace (expandable)
  • Badge "Box Custom" vs "Box Zin"
  • Preview thumbnail của từng size
  • Click → move to Step 2

Step 2 — Upload ảnh xe

  • Drag & drop hoặc click to browse
  • Crop tool: khoanh vùng xe
  • "Safe zone" overlay: vùng xe nên nằm trong
  • Auto-suggest: remove background (AI)
  • Upload lên Supabase Storage ngay

Step 3 — Customize

  • Tên xe (input) — render canvas
  • Thông số: Engine, Power, Torque, Top Speed, Acceleration
  • Logo hãng: dropdown variant (MiniGT / Poprace / Custom)
  • Color picker: nền hộp, accent line, text color
  • Credit text (input, optional)
  • Live update 3D preview realtime

Step 4 — Preview & Order

  • 3D box tự xoay, drag để spin
  • Toggle "Flat view" → xem layout in phẳng
  • Nút "Download PDF" (nếu chọn self-print)
  • Nút "Add to Cart" (print & ship)
  • Quantity selector ngay tại đây
  • Save design → link shareable
💡 UX insight: Giữ 3D preview cố định ở right panel suốt step 2–4. Khách không cần "tưởng tượng" — thấy ngay kết quả khi gõ từng chữ.

2 cột: Order summary (trái) + Form thanh toán (phải)

Checkout Form — Address Book (UX key)

Nhập SĐT
→
Debounce 400ms → query Supabase → nếu có địa chỉ saved → dropdown hiện ra
Có địa chỉ
→
Click chọn → form tự fill. "Sử dụng địa chỉ khác" để nhập mới
Không có
→
Nhập bình thường + toggle "Lưu địa chỉ này" → verify OTP → save
Country detect
→
Nếu chọn country ≠ VN → ẩn VNPay/MoMo, hiện PayPal. Nếu VN → VNPay/MoMo mặc định
✅ Upsell rule: Threshold free ship cấu hình trong admin (mặc định 5 box). Progress bar trong cart drawer hiện động: "Còn 2 box nữa → miễn phí ship toàn quốc 🎉"
Flow 3 — Post-payment Experience
Payment OK
→
Webhook từ VNPay/PayPal → Supabase update order status → redirect /checkout/success
🎬 Animation
→
Full-screen: flat box panels → fold → assemble 3D → close → ✓ checkmark · Duration 3–3.5s · Spring physics · Không thể skip (nhưng không block)
Order Summary
→
Mã đơn hàng · "Hàng được gửi trong 5 ngày làm việc" · Nút "Theo dõi đơn hàng" → /track · Email xác nhận tự động
💡 Animation là brand moment quan trọng nhất. Đây là lần đầu khách "thấy" hộp của mình được lắp ráp → emotional payoff sau khi mua.
Flow 4 — Promotions & Pre-order Logic

🏷️ Sale Off

  • Admin set: N% off cho dòng xe / loại hộp / toàn bộ
  • Countdown timer tự tắt khi hết giờ
  • Giá tự revert về gốc
  • Sticky banner ở top
  • Badge đỏ trên product card

⏳ Pre-order

  • Product flag: is_pre_order = true
  • Countdown đến ngày đóng PO
  • Label "PRE-ORDER" thay "Sale Off"
  • Sau khi hết countdown: giá về gốc, label ẩn
  • Always full payment upfront
  • Email confirm: ETA ship date

🎯 Admin Config

  • Promotion type: product / category / all
  • Discount: % hoặc fixed amount
  • Start + End datetime picker
  • Preview trước khi publish
  • One-click pause/resume
  • Stacking rules (chỉ apply 1 promo)
⚡ Countdown timer sync với server time (không dùng client Date.now()) → tránh lệch giờ khi khách ở múi giờ khác trong SEA.
Flow 5 — Admin Panel

📊 Dashboard

  • Doanh thu hôm nay / tuần / tháng
  • Đơn mới realtime (live badge)
  • Top sản phẩm bán chạy
  • Tỷ lệ custom vs catalog
  • Đơn pre-order pending

📦 Orders

  • Table: filter by status
  • Status flow: Pending → Processing → Shipped → Done
  • Click đơn → xem design khách tạo
  • Nhập mã vận đơn → auto email khách
  • Bulk: mark shipped nhiều đơn 1 lúc

🛍️ Products & Templates

  • Add/edit/archive sản phẩm
  • Upload ảnh nhiều góc
  • Set pre-order flag + date
  • Manage box templates (components config)
  • Manage size types
